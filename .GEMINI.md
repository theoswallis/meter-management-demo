# Project Guidelines & Agent Instructions

## Prompt Logging & AI Disclosure
1. **Log Every User Prompt:**
   - For complete accountability and take-home project transparency, whenever the user sends a prompt or instruction in any conversation, append the user's prompt to `prompts.log` at the project root.
   - Format entries with the local timestamp, for example:
     ```
     [YYYY-MM-DD HH:MM:SS TZ]
     <user prompt>
     ```
